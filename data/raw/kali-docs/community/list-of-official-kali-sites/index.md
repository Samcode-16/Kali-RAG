The [Kali Linux project](/) uses various <!--domains and--> subdomains of kali.org, each with a specific purpose. This article lists the official Kali sites and the purpose each one of them serves. _Note that these sites are the **only** official Kali Linux sites_ and are _the only authoritative sources of information_ available for the distribution.

{{% notice info %}}
The sites listed below are the ONLY official outlets for the Kali Linux distribution.
{{% /notice %}}

## Public Websites

**[www.kali.org](/)**

<!-- `www.kali.org`: The official website of Kali Linux! Users can find links to downloads, the blog, documentation, and more.-->
The main [Kali Linux website](/) is our primary means of communicating news about the Kali Linux project, general introductory information, and general updates about the project and its ongoing development.

[Blog posts](/blog/) about new tools, features, tips, tricks, and tutorials can be found here. This should be _your one and only source_ to [download](/get-kali/) the official Kali Linux distribution. Both these have an RSS feed: [Blog](/rss.xml) and [Torrents](/torrents.xml)

- - -

**[bugs.kali.org](https://bugs.kali.org/)**

<!-- `bugs.kali.org/`: Any time a user has an issue that is sure to be a bug, they should report that bug here to our bug tracker.-->
Despite our best efforts at making Kali Linux perfect, bugs and errors are inevitable. We are always open to making improvements and can only effectively do so when issues or tools suggestions are reported to us. You are encouraged to submit bug reports at [bugs.kali.org](https://bugs.kali.org/) to help us make Kali Linux even better.

More information on submitting bug reports to the Kali Linux project can be found in [this article](/docs/community/submitting-issues-kali-bug-tracker/).

- - -

**[status.kali.org](https://status.kali.org/)**

Should any site be down for you, you can check their status here.

- - -

**[arm.kali.org](https://arm.kali.org/)** & **[nethunter.kali.org](https://nethunter.kali.org/)**

Automatically generated sites for their designated platforms to give high level overview as well as low level detailed understanding.

**[kali.org/tools/](/tools/)**

The core of Kali Linux is the [comprehensive toolset](/tools/), drawn from many different sources in the security and forensics software community. The tools site provides both an up-to-date listing of the tools which are available in Kali Linux, as well as providing a quick reference to each of them. From here, the versions of the tools can be tracked against their upstream sources.

### Community

**[forums.kali.org](https://forums.kali.org/)**

<!-- `forums.kali.org/`: A site where users can go to when in need of assistance. Issues related to hardware, software, and general information related to Kali is discussed with the help of other community members.-->
If you run into an issue or situation that isn't directly covered in the [official Kali Linux OS documentation](/docs/), there is a good chance that a member of the [Kali Linux Forums](https://forums.kali.org/) will know the answer. The Kali forum has members from all over the world, covering the entire range of skill levels, and are open and willing to help newcomers who are willing to learn.

More information on the Kali Linux Forums can be found in [this article](/docs/community/kali-linux-community-forums/).

- - -

**[discord.kali.org](https://discord.kali.org/)**

We have an active Discord server, which are you welcome to chat in real-time all about Kali Linux.

- - -

**[irc.oftc.net/#kali-linux](ircs://irc.oftc.net/#kali-linux)**

If Discord is not your thing, but you still want to chat real-time all about Kali Linux, then Internet Relay Chat (IRC) may work for you!

We also have a few development bots running if you want to see the internal workings a bit more!

### Mirrors

**[http.kali.org](https://http.kali.org/)**

A redirector, which will point to [your closest mirror](https://http.kali.org/README?mirrorlist), when you try and download a package (think `apt`).

- - -

**[cdimage.kali.org](https://cdimage.kali.org/)**

Another redirector, which will point to [your closest mirror](https://cdimage.kali.org/README?mirrorlist), when you try and [download](/get-kali/) a image.

- - -

**[kali.download](https://kali.download/)**

A mirror that utilizes Cloudflare's content delivery network (CDN). <!-- https://blog.cloudflare.com/cloudflare-repositories-ftw/ -->

- - -

**[archive\*.kali.org](https://archive.kali.org/)**

Mirrors which match, are Kali mirrors which are run by us.

- - -

**[old.kali.org](https://old.kali.org/)**

If for any reason a user needs an old copy of Kali Linux, then this is the site for them. Images & packages from some of the first Kali releases can be found as well as more recent releases.

- - -

**[mirror-traces.kali.org](https://mirror-traces.kali.org/)**

This tracks Kali mirror network, either ran by us or [community contributed](/docs/community/setting-up-a-kali-linux-mirror/). This will monitor how "fresh" _(aka up-to-date/in-sync)_ a mirror is.

The [Kali Linux Package Tracker](https://pkg.kali.org/) site allows you to follow the evolution of Kali Linux both with email updates and a comprehensive web interface. The tracker can also help in identifying which versions of various tools and packages are in our repository at any given moment.

**[autopkgtest.kali.org](https://autopkgtest.kali.org/)**

Many packages have a test that is associated with it to ensure that they run. This site shows all of those tests and whether they pass or fail.

- - -

**[build-\*.kali.org](https://repo.kali.org/build-logs/)** & **[images-\*.kali.org](https://repo.kali.org/build-logs/)**

**[repo.kali.org](https://repo.kali.org/)**

This is the heart of our Kali development. It is responsible for orchestrating the build machines to process our packages and images, as well as migrating packages from [branches](/docs/general-use/kali-branches/).
It is also the first piece of our mirror setup.

- - -

**[jenkins.kali.org](https://jenkins.kali.org/)**

This runs various daily checks to help QA Kali.

## External

**[gitlab.com/kalilinux](https://gitlab.com/kalilinux/)**

This site is the Kali Linux project's [official git repository](https://gitlab.com/kalilinux) and is publicly accessible. Most users will never need to interact with it directly, but users who wish to more closely monitor the development of Kali Linux, or people who want to know when they should run `sudo apt full-upgrade -y`, can peruse or clone the repository.

- - -

**[kali.training](https://kali.training/)**

New or experienced users of Kali may wish to gain a greater knowledge of Kali, which is covered in this site. Kali Training lets users go through the Kali Linux Revealed book and complete practice tests associated with the content of chapters. This is all to prepare for the KLCP (Kali Linux Certified Professional) exam.

- - -

**[video.infosec.exchange/c/kalilinux](https://video.infosec.exchange/c/kalilinux/videos)**

A PeerTube instance, which has all our created videos hosted on.
